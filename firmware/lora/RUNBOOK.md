# Fence gossip runbook

All names are PLACEHOLDERs. Draft PR only — do not merge until protocol/HAL owners agree.

## Layout

```
firmware/lora/          portable library (no Zephyr)
  include/opencollar/   public headers (radio_hal.h, fence_*.h)
  src/                  implementation
  tests/                host tests
  vectors/              committed hex KATs (regenerated by test_vectors)
  NOTES.md              assumptions + lora.md §1 deviation
  Makefile

firmware/sim/           host virtual radio (implements radio_hal.h)
```

## Build and test

```bash
make -C firmware/lora test
```

Runs (all must pass):

| Binary | Coverage |
|---|---|
| `test_vectors` | Manifest/fragment/NEED KATs, tampered body, bad signature |
| `test_onehop` | One-hop handoff; 0% / 30% / 50% loss (`starling_serve` OFF) |
| `test_chain` | Multi-hop 3-node chain at 30% loss (`starling_serve` ON); newer supersedes; partition heal |
| `test_security` | Forged beacon (hint only); forged manifest; rollback; dup/reorder/resume |

### 30% loss report (1000 seeds, one-hop)

```bash
make -C firmware/lora loss
# or: ./firmware/lora/build/test_onehop --loss30
```

### Clean

```bash
make -C firmware/lora clean
```

## Config flags

- `starling_serve` — PLACEHOLDER. **Default OFF** (`OC_FH_STARLING_SERVE_DEFAULT`).
  Rooks always serve. Set to 1 only for multi-hop gossip sims/tests.
- Pilot telemetry remains one hop to the Rook (not implemented in this library).

## Simulator

Virtual radio driven by the tests (implements full `radio_hal.h` including init,
sleep, now_us, limits).

- Two-node: `tests/test_onehop.c`
- N-node chain / partition: `tests/test_chain.c`
- Link knobs: `sim_link_t` — `loss_pct`, `burst_*`, `reorder_pct`, `duplicate_pct`, latency;
  seeded via `sim_world_init(..., seed)`.
