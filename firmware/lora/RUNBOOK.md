# Fence gossip runbook

## Layout

```
firmware/lora/          portable library (no Zephyr)
  include/opencollar/   public headers (radio_hal.h, fence_*.h)
  src/                  implementation
  tests/                host tests
  vectors/              committed hex KATs (regenerated by test_vectors)
  NOTES.md              assumptions
  Makefile

firmware/sim/           host virtual radio (implements radio_hal.h)
```

## Build and test

```bash
make -C firmware/lora test
```

Runs: `test_vectors`, `test_onehop`, `test_chain`, `test_security`.

### 30% loss report (1000 seeds)

```bash
make -C firmware/lora loss
# or: ./firmware/lora/build/test_onehop --loss30
```

### Clean

```bash
make -C firmware/lora clean
```

## Simulator

The virtual radio is driven by the tests (no separate CLI required for milestones).

- Two-node: `tests/test_onehop.c`
- N-node chain / partition: `tests/test_chain.c`
- Link knobs: `sim_link_t` — `loss_pct`, `burst_*`, `reorder_pct`, `duplicate_pct`, latency; seeded via `sim_world_init(..., seed)`.

Example (from a future harness): set a chain with `sim_world_set_chain`, toggle `starling_serve` on node configs.

## Regenerate vectors

```bash
make -C firmware/lora build/test_vectors
cd firmware/lora && ./build/test_vectors
# writes vectors/manifest_body.hex, manifest_sealed.hex, pubkey.hex
```

## Zephyr native_sim

```bash
make -C firmware/lora native_sim   # prints stub notice
```

Host sim is the supported path for CI until a Zephyr target is wired.
