# Starling

nRF52840 LoRa collar: signed fences over LoRa (from a Rook, mesh-relayed across
Starlings when `starling_serve` is on), enforced on local GNSS. No BLE in the
pilot.

See [RUNBOOK.md](RUNBOOK.md) for build, fake-GNSS demo, and flash steps.
