# A — Soft organic

**Intent:** A collar that feels like jewellery for a working dog — continuous
curves, no knife edges, volumes that read as one pebble rather than a bolted box.

## Form

- Outer shells are heavily rounded boxes (cap R≈10, pod R≈11, cw R≈10) so every
  vertical silhouette edge is a large radius — a continuous soft pill.
- No decorative seams or facet lines. Sound / cable ports are the only
  interruptions on the pod.

## Hardware envelope

Unchanged: 76×160 cap footprint, pod cavity 82×58×21.5, same column and clamp
XY. Floor thicknesses match the slim / saddle stack so M3 inserts still seat.

## Print

Bed face flat. Large radii are ≥45° equivalent on the flanks — no supports on
P2S PLA/ASA. Prefer a brim on ASA for the tall pod/cw.

## Trade-offs

- Softer outer wall means less “grippy” flat for labels / branding.
- O-ring groove and lid mate are not modelled here (concept shell only).
